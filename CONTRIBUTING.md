# Contributing

Thanks for helping improve X-TREME PLAY'S.

1. Open an issue to discuss a larger feature before starting it.
2. Make changes on a branch and keep each pull request focused.
3. Build the Windows app with `dotnet build src/XtremePlays.App/XtremePlays.App.csproj --configuration Release --runtime win-x64`.
4. Describe the behavior you changed and the Windows version you used to verify it.

Do not include browser profile data, credentials, private audio, or personal information in issues or pull requests. Changes to the bundled VB-CABLE package need to preserve the vendor's original files and distribution notice.
